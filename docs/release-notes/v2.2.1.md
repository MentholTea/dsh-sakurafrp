## 修复：日志收起后，切换页面回来又自动展开

**症状**：把 frpc 日志收起来，切到别的设置页再切回「内网穿透」，日志又变成展开状态。
反复收、反复弹，像是「关闭按钮不生效」。

**原因**：展开状态用的是组件内的 `useState(true)`。DSH 设置页切换时会卸载并重建
组件，`useState` 的初始值重新生效——用户的选择没有被记住，每次都回到默认的「展开」。

**修法**：把选择存进 `localStorage`（键 `dsh-sakurafrp:logsOpen`），组件挂载时读回来。
这是纯前端 UI 偏好，不写服务端 `state.json`，省一次 IO、也不受 4 秒轮询覆盖的影响。

两个刻意的退化行为：

- **没存过 → 默认展开。** 默认展开是设计意图：连不上、端口被抢这类问题只有日志里有答案，
  藏起来等于让人先猜一次。
- **存储被禁（隐私模式等）→ 仍然展开。** 读失败不能让日志消失。
  写失败则静默忽略，最坏情况只是下次回到默认展开。
