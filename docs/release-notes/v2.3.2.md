## 安装

```powershell
dsh plugin --profile desktop add dsh-sakurafrp -w
```

装不上就换这条（同为 2.3.2，取本 Release 的预构建包）：

```powershell
dsh plugin --profile desktop add https://github.com/MentholTea/dsh-sakurafrp/releases/latest/download/dsh-sakurafrp.tgz -w
```

## 修复：手机端白屏（只有桌宠显示）

DSH 升级后，手机通过隧道打开会是白屏，只看得见桌宠。

已修。网关现在会自动纠正 `dsh-web-mobile` 移动端样式里一条把主内容宽度压成 0 的
网格列定义，页面恢复正常显示。不改第三方插件文件，重启 DSH 后生效。

## 修复：重定向次数过多 / 需要清 Cookie

登录后不断跳转、最后报「重定向次数过多」，清 Cookie 也不管用。

已修。现在：

- 补发过一次登录令牌后不再重复补发，从源头断掉循环；
- 浏览器连续存不住 Cookie 时会停下来给出说明页，而不是继续重定向；
- DSH 换端口导致旧会话失效时，会自动清理一次并重新登录，不用再手动删 Cookie。

## 其他

- 手机端复选框/单选框放大到 24px，便于点按。
- 新增 `test/gate-redirect-test.mjs`（12 项）覆盖上述登录链路。

## 升级方式

```powershell
dsh plugin --profile desktop add dsh-sakurafrp@2.3.2 -w
```

装完重启 DSH。已配置的隧道、端口、密码、密钥都会保留，本地 frpc 不会被重装。
