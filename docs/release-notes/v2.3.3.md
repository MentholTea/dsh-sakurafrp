```powershell
dsh plugin --profile desktop add dsh-sakurafrp -w
```

装不上就换这条（同为 2.3.3，取本 Release 的预构建包）：

```powershell
dsh plugin --profile desktop add https://github.com/MentholTea/dsh-sakurafrp/releases/latest/download/dsh-sakurafrp.tgz -w
```

## 修复：frpc 日志时间显示的是 UTC，不是本机时间

面板里的日志一直长这样：

```
[2026-11-06T10:26:55.493Z] TCP 隧道启动成功
```

`Z` 表示 UTC。北京时间 18:26 启动的隧道，日志写成 10:26，对照 frpc 原始输出、
排查断线时间点都对不上号。

现在改成 **本机本地时间**，去掉毫秒，读起来更直接：

```
[2026-11-06 18:26:55] TCP 隧道启动成功
```

时间戳由 `frpc.mjs` 手工拼装（`YYYY-MM-DD HH:mm:ss`），不走 `toLocaleString`——
后者依赖 ICU 和 locale，精简构建或不同系统区域设置下格式会漂移。

## 其他

- `test/fixes-test.mjs` 新增 3 项回归断言：格式为 `YYYY-MM-DD HH:mm:ss`、
  不再带 UTC 的 `Z` 后缀、解析出的时刻与本机当前时间相差 5 秒以内（若回退成 UTC
  会差出整 8 小时，直接被抓到）。

## 升级方式

```powershell
dsh plugin --profile desktop add dsh-sakurafrp@2.3.3 -w
```

装完重启 DSH。已配置的隧道、端口、密码、密钥都会保留，本地 frpc 不会被重装。
