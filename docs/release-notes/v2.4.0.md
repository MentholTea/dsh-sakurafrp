## 安装

```powershell
dsh plugin --profile desktop add dsh-sakurafrp -w
```

装不上就换这条（同为 2.4.0，取本 Release 的预构建包）：

```powershell
dsh plugin --profile desktop add https://github.com/MentholTea/dsh-sakurafrp/releases/latest/download/dsh-sakurafrp.tgz -w
```

## 新增：删除隧道

在「② 隧道」里选中一条之后，右侧会出现**删除隧道**。以前想删一条隧道只能去
SakuraFrp 官网，现在面板里就能做。

- 只删**当前选中的那条**，删前弹确认框，并写清删的是哪一条、公网入口是多少
- 删的正好是当前隧道时，插件同步停 frpc、清空 `tunnelId`、把开关落回关闭——
  不会留下「开关还亮着，公网入口已经没了」的状态
- 远端删失败（隧道已不存在 / 不属于当前账号 / API 报错）时，本地配置一个字都不动，
  可以直接重试

官方 `POST /tunnel/delete` 的返回是 `{ deleted, failed }`，其中 `failed` **不是删除失败**，
而是「已经删掉了、但没能把在线的 frpc 踢下线」。所以插件只看 `deleted` 判断成功；
`failed` 里的 id 仍算删除成功，只是本地会自己把 frpc 停掉，避免它拿着一条不存在的
隧道反复重连。

> 删除不可恢复。只是想换端口或节点的话，改设置就行，不必删隧道。

## 修复：深色模式输入框白底白字

深色主题下，面板里的输入框看上去是**空的**——其实内容还在，只是白底配了浅色文字。

原因是 `client.js` 引用了 `--dsw-alias-bg-1` / `--dsw-alias-border-1` 这两个 token，
它们在 DSH 宿主里**根本不存在**，于是 CSS fallback 永远取到 `#fff`；而文字颜色是继承的，
深色模式下变成浅色，就成了白底白字。

现在全部换成宿主真实存在的 token：

| 用途 | 旧（不存在） | 新（真实 token） |
|---|---|---|
| 输入框背景 | `--dsw-alias-bg-1` | `--dsw-alias-bg-layer-2` |
| 输入框文字 | 继承 | `--dsw-alias-label-primary` |
| 边框 / 分割线 | `--dsw-alias-border-1` | `--dsw-alias-border-l1` |
| 开关关闭态 | `--dsw-alias-border-2` | `--dsw-alias-border-l2` |

顺带修了 placeholder：内联 style 命不中 `::placeholder`，改用面板内的 `<style>` 下发，
作用域限定在 `[data-natfrp-panel]`，不会污染宿主或其它插件。

## 升级方式

```powershell
dsh plugin --profile desktop add dsh-sakurafrp@2.4.0 -w
```

装完重启 DSH。已配置的隧道、端口、密码、密钥都会保留，本地 frpc 不会被重装。
